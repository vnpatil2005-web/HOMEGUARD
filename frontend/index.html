About HOMEGUARD

Smart Home Security Using Human Presence Detection

HOMEGUARD

HOMEGUARD is an IoT-based home security system designed to detect human presence in a restricted area and notify authorized users.

How it works

The HLK-LD2410B human presence sensor detects presence and communicates with the ESP32. The ESP32 sends detection information to the cloud, allowing users to monitor their area remotely.

Hardware Used

  • ESP32 DevKit V1
  • HLK-LD2410B Human Presence Sensor
  • Buzzer
  • Rechargeable 18650 Battery

Software Technologies

  • HTML, CSS and JavaScript
  • Firebase Cloud Firestore
  • Firebase Authentication
  • Firebase Cloud Messaging
